# Library Management System

## Project Description

The Library Management System is a web-based application developed using Python Flask. 
It helps to manage books in a library easily and efficiently.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite Database

## Features

- Add new books
- View all books
- Issue books
- Return books
- Check book availability
- Store book details in database

## Frontend

The frontend is developed using:
- HTML
- CSS

## Backend

The backend is developed using:
- Python
- Flask

## Database

SQLite is used to store the book details.
